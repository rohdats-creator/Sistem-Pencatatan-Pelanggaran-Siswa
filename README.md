# Sistem-Pencatatan-Pelanggaran-Siswa
Sistem Pencatatan Pelanggaran &amp; Poin Siswa merupakan aplikasi berbasis digital yang dirancang untuk membantu jurusan teknik kendaraan ringan dalam melakukan pencatatan, pemantauan, pengelolaan, dan pelaporan pelanggaran tata tertib siswa secara terstruktur, transparan, dan efisien.
